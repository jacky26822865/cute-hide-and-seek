# 可愛捉迷藏（免伺服器連線版）

3D 多人連線密室遊戲。純靜態網頁，放在 GitHub Pages 就能玩：
- 同一個房號＝同一局；第一位進房的玩家的瀏覽器會擔任「中繼」，離開或當機時，剩下的玩家會在幾秒內自動選出新中繼
- 右上角有全隊共用的「主線進度」（按 J 收合）與隊友狀態（按 T 收合），任何人推進主線時全隊都會收到提示
- 玩家之間以 WebRTC 直連（配對使用 PeerJS 公用服務），支援附近才聽得到的語音
